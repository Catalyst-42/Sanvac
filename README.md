# Sanvac
An infinite canvas with cards, text images and notes. And secrets, i guess. Made with usage of Claude and a little bit of my personal brain

![Sanvac - Example](<img/Sanvac - Example.png>)

A canvas can be set up with `data.json` file.

Type of cards available: 
- text
- photo
- video
- note
- sticker

Objects on canvas are draggable. You also can change layers and stack objects on each other. Canvas in infinite and can hold a secrets outside of its bounds or on far coordinates. 

Movement:
- Movement on `WASD`
- Movement on `Mouse drag`
- Fast movement on `Shift` + `WASD`
- Confetti on `B`
- Download save on `I`
- Toggle coordinates on `M`
- Show coordinates on `Alt`
